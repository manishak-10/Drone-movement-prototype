# 🚁 Drone Movement Prototype

A small 3D drone prototype created using Godot Engine and GDScript to explore movement, controls, and basic game development.

## 🎮 What I Built

- Drone movement
- Up and down movement
- Left and right movement
- Basic 3D environment
- Camera setup
- Motor movement
- Basic controls

## 🛠️ Tools Used

- Godot Engine
- GDScript
- 3D Game Development
